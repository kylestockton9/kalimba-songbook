# Kalimba Songbook

Learn tunes on a 17-key kalimba tuned in C. The key to play next lights up; tap it, press Play to follow along, or turn on Listen and the app advances as you pluck your own kalimba.

Live: https://kylestockton9.github.io/kalimba-songbook/

`index.html` is the app source. Run `build.ps1` to rebuild `docs/index.html`, the page GitHub Pages serves.
